# Changelog

## 0.0.1 (unreleased)
- Docs: README, user guide, admin guide, architecture overview, third-party notices, synthetic-data screenshots of the main window.
- M5 (UI half): main window with session name, source toggles, status pill, Start/Pause/Resume/End, live pane with follow mode, "Return to live" pill and End key (SPEC 8.2), typed backend API with a browser mock, vitest for the follow rules. Tauri commands behind it arrive with Windows capture.
- M2 (portable core): `Session` orchestrator (Me/Others streams, VAD, decode, commit buffer, writer sink, pause/resume with visible gaps, source toggles, remote label that never rewrites committed lines), counters-only stats.
- M8/M9 (portable core): meeting selection rules (cancelled, all-day, free skipped; in-progress first, then within 15 min), platform detection, redacting `Meeting` Debug, Meeting context section; handoff prompt template (user, admin, bundled), Claude link builder with 14k cap and clipboard fallback, Copilot plan, policy visibility, `Launcher` seam.
- M7 (portable core): transcript parser (front matter, statements, events, optional sidecar merge), `Exporter` trait with txt, json and docx adapters, Participants and Audio sources sections and `call:`/`audio_sources:` front matter rebuilt at finalize from event lines.
- M15 (everything not needing a key): SSHSIG Ed25519 verification (namespace `sprknotes-model`), trusted key parsing and fingerprints, two-key rotation, trust tiers (signing always required from 1.0, cannot be disabled by policy), load-time signature re-check, `sprkctl model sign` via ssh-keygen and the 1Password agent, `docs/manual-checks.md`.
- M10 (portable core): model stores (active.json, activate, rollback, prune, remove), resolver (pinned, machine, user, bundled, allow-list, fallback), .sprkmodel pack and verify (zip-slip, size limits, allow-list, signature trait), import flow with staging, smoke test and rejects, `sprkctl model pack|verify|hash|install|import|list|activate|rollback|remove` with RMM exit codes.
- M11/M12 (portable core): audio source activity tracker with the 18.4 timing rules and exclusions; call title parsing and labeling modes with two-poll hysteresis and spec event lines.
- M3 (portable core): transcript format 5.1 writer (append + flush, sidecar JSONL, atomic finalize, rename ranking), naming and sanitizing, crash recovery; commit buffer with filler filter, fragment merge, long-utterance split and bleed dedupe (M4 layer 3). ADR-003 accepted (Parakeet).
- M1: `model.json` schema 1 (parse, validate, hash verify), engine registry, sherpa-onnx adapters (Parakeet transducer, Whisper) and Silero VAD, WAV reader, WER scoring, streaming resampler, `sprkctl transcribe` (WAV and live mic) and `sprkctl bench accuracy`, `scripts/bench.sh`, fetch scripts, ADR-003 (proposed, laptop numbers pending).
- M0: workspace scaffold, platform seam traits and fakes, Tauri + Svelte shell, dev scripts, ADR-001 and ADR-002.
