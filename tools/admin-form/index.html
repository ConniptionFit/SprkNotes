SprkNotes deployment scripts

Choose settings, then copy two scripts into NinjaOne (or any RMM). This page works offline and sends nothing anywhere.

How it fits together

Locked settings go in a script that runs as SYSTEM and writes HKLM\SOFTWARE\Policies\SprkNotes. Only administrators can change that key, so people cannot undo it, and SprkNotes shows those settings as set by your organization.

Starting value settings are baked into the install script, which runs as the signed-in user and installs SprkNotes into their own profile. People can change starting values later.

Paths can use %OneDrive%, %USERPROFILE% and similar. They are stored as written and filled in for each person when SprkNotes runs.
